# linktree | Dra. Renata Ribeiro

Um linktree minimalista e elegante desenvolvido para a **Dra. Renata Ribeiro**, especialista em **Harmonização Orofacial**. O projeto tem como objetivo centralizar, em uma única página, os principais canais de contato da profissional.

## Funcionalidades

* Link para agendamento via WhatsApp
* Link para localização da clínica no Google Maps
* Link para avaliação no Google
* Design minimalista e responsivo
* Compatível com dispositivos móveis e desktop

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3

## 🚀 Como executar

1. Clone este repositório:

```bash
git clone https://github.com/seu-usuario/nome-do-repositorio.git
```

2. Acesse a pasta do projeto:

```bash
cd nome-do-repositorio
```

3. Abra o arquivo `index.html` em seu navegador ou utilize a extensão **Live Server** no Visual Studio Code.


## 📱 Responsividade

O layout foi desenvolvido com foco em dispositivos móveis, mantendo uma boa experiência também em tablets e desktops.
